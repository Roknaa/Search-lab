# SEARCH Website v2.0

منصة تعليمية عربية بتصميم سينمائي/مستقبلي، مبنية بملفات ثابتة مناسبة للنشر على GitHub Pages.

## المعمارية
- `components.js`: الهيدر والفوتر والتنقل المشترك.
- `main.js`: السلوك العام للموقع واستجابة الموبايل والكمبيوتر والبحث واللغة.
- `style.css`: نظام التصميم الكامل لكل الصفحات.
- `projects/`: مكتبة المشاريع، وكل تجربة في مجلد مستقل.
- `projects/<slug>/project.js`: منطق التجربة فقط، وليس وظائف الموقع العامة.

## التشغيل محليًا
من داخل مجلد المشروع:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع المجلد الأب نفسه).
3. افتح Settings → Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)`.
5. احفظ وانتظر رابط النشر.

## إضافة مشروع جديد
1. أنشئ مجلدًا داخل `projects/` باسم إنجليزي قصير.
2. أضف `index.html` وملف `project.js` عند الحاجة.
3. استخدم `../../style.css` و`../../components.js` و`../../main.js`.
4. أضف بطاقة المشروع إلى `projects/index.html`.
5. أضف تصنيفًا وعبارات بحث في خصائص `data-category` و`data-search`.

## ملاحظات تقنية
- لا توجد لوحة تحكم أو قاعدة بيانات في هذا الإصدار.
- لا توجد ملفات jQuery أو مكتبة SVG إضافية محمّلة حاليًا؛ يمكن إدخالها داخل المشروع الذي يحتاجها فقط. Canvas مستخدم في تجربة السماء الزرقاء.
- الخطوط وأيقونات Phosphor تُحمّل من CDN، لذلك تحتاج اتصال إنترنت لعرضها.
- المحاكاة العلمية توضيحية وليست نموذجًا عدديًا كاملًا.
- أزرار الإنجليزية حاليًا تبدّل اتجاه/وضع الصفحة كبنية أولية؛ ترجمة جميع النصوص مرحلة مستقلة لاحقة.
- GitHub Pages يستضيف ملفات ثابتة فقط؛ الحسابات وقاعدة البيانات تتطلب خدمة خلفية لاحقًا.
